记录下折腾和学习的过程

Claude Code时代的手动挡思维

May 6, 2026 • admin

categories : 杂谈

扫描二维码

卖掉BRZ那天，是个晴天。

下午三点的光打在蓝色车身上，金色轮毂折射出一圈碎光。绿头CD机放着《Tokyo Drift》——我从大学听到现在的碟，虽然从未学会漂移。交钥匙前发动了最后一次，FA20从低吟拉到高转。买家小我六岁，跳上车那一刻笑得像个孩子。

理想L7什么都会——自动泊车、NOA导航、语音控制。BRZ什么都不会——转速得自己听、补油得自己踩、跟趾得自己练。每个动作都是你和车在对话。

交钥匙那一刻我想起《禅与摩托车维修艺术》。Pirsig说，技术不是问题，问题是你和技术的关系。BRZ是古典理解——拆得开、听得懂、摸得着。L7是纯浪漫——舒服、聪明，但你不知道它内部在做什么。

不是卖一辆车。是古典向浪漫的投降。

但卖车归卖车。写代码这件事，我没有完全交给自动驾驶。

我现在只用Claude Code，IDE早卸了。但我跟新手用AI是两回事。新手是 spec acceptance——”帮我写一个登录系统”，丢需求，收代码，跑通了就过了。我是 spec coding——先理解业务、拆PRD、画时序图、写技术方案，然后再把方案丢给AI执行。

区别在哪？我写的不是 prompt，是 design doc。AI 在我手里不是代驾，是帮踩油门的——方向盘还在我手上。

效果很直观：交付速度翻了几倍，但质量没有下降。因为质量从来不是代码写得快决定的，是架构、边界条件、异常路径——这些东西 AI 猜不出来，只有你看过足够多的血能预判。

这就是Pirsig说的古典理解——你知道它为什么能跑，也知道它会在哪里炸。AI让你很快，但只有古典理解让你正确。

深夜刷番茄小说，一本西溪旧月的《末世从AI觉醒开始崛起！》——写到320章还在连载，讲AI研发工程师重生后灵魂与AI融合，跑到修炼文明里搞元宇宙。推荐栏还有《AI取代程序员》《GPT之后，代码不再需要人类》《我被Copilot开除了》。

两层黑色幽默：这些大概率是AI生成的网文，在说AI会干掉程序员；而另一群程序员正用AI写网文收割稿费。套娃。

Pirsig警告过”鬼魂”：技术太聪明，你就看不见它背后的形式。当你只会prompt不会debug，只看得懂diff看不懂调用栈，你就从驾驶员变成了乘客。车还是能到目的地，但撞护栏的时候你不知道该打多少方向。

这不是危言耸听。会用Claude Code的人已经很多了，真正懂它生成什么的人少得可怜。

两种方式，我都有体会。

开BRZ上龙泉山狮子堡：全程盘山路，右手挡杆和方向盘之间来回，左脚跟趾补油，耳朵追着FA20从两千转到七千转的声线变化。每个回头弯都在和物理定律谈判。到山顶手心全是汗，但你知道是自己开上来的。

Pirsig在书里有一段写摩旅时的状态——当你骑在摩托上，两手握把，身体随弯倾斜，整个世界被压缩成下一个弯、下一脚刹车、下一段路面。没有过去、没有未来，只有此刻。这就是心流。开手动挡上盘山路一样：转速表的每一次跳动都在把你钉在当下，你没法想昨晚的bug，没法想明天的站会。你在开车，仅此而已。

今年开L7自驾去了趟内蒙古。成都出发，两千多公里，NOA开着，座椅按摩开着。以前一个人开长途最多撑4小时，现在一天跑800公里，到了还能吃羊肉。不是吹NOA有多牛——是它帮你吃掉所有机械疲劳，把精力留给你真正需要判断的时刻。

这就是Claude Code的真相：不是让你变懒，是让你变快。AI替你写样板、撸测试、查日志，省掉的不是决策，是体力活。你省下来的精力，刚好够盯住它会不会在并发那里埋雷。

但有一说一，NOA开着的时候我确实不在心流里。座椅按摩加自适应巡航，人是松的。BRZ过弯我不敢走神，走神就是护栏；L7跑高速我敢走神——前面200公里都是直路。两个场景都对，区别在于你知道什么时候需要心流，什么时候可以放手。

我投BTC的方式也像开BRZ。

2022年$22k建仓，不看K线，不追土狗，不碰合约。拿到就囤着，像开一辆老油车，不换新款也不羡慕隔壁加速。2024年底$100k附近分批卖出，近5倍。

段永平说”慢就是快”，币圈也一样。长持是对”确定性”的信仰，就像你相信一台水平对置发动机拉到七千转不会散架。

这是古典投资观——像Pirsig修摩托：耐心拆解，等待反馈，信任底层逻辑。

美股还没找到那支愿意握十年的标的。巴菲特说”没人愿意慢慢变富”，我倒不是不愿意，是还在学怎么在慢车道上平稳挂挡。

《Tokyo Drift》还在手机里——虽然我从未学会漂移。有些事情不需要完成，只需要存在。车库角落还留着没用过的改装离合、一张富士赛道门票、一个永远不删的改装件购物车。

Pirsig骑老摩托穿越美国，不是反对新技术，是”维修”自己和世界的关系。我周末偶尔关掉AI，纯手动写一段代码，也不是抗拒——是确认自己还能和机器对话，而不是只会下命令。

真正的出路不是选择古典还是浪漫。是像Pirsig说的：保持gumption，保持对品质的敏感。用AI加速原型、生成样板，但核心逻辑自己把关。享受浪漫速度，保留古典深度。

未来属于会用车机的人。但出了bug还能修的人，才配得上那台车机。

BRZ卖了，我不后悔——两个世界我都去过。但无论方向盘怎么变，手还在。
